# Design system

Visual thesis: **architectural calm under technical control**—deep navy structure, precise cyan measurement cues, warm restored surfaces, and an editorial rather than card-grid composition.

Logo-derived palette: Navy `#073B66`, deep ink `#061B2C`, water `#058ED9`, cyan `#62D7E8`, warm paper `#F6F4EF`, white `#FFFFFF`, charcoal `#18242D`, muted `#60717D`. WCAG contrast is maintained for functional text.

Typography uses the local/system stack `Inter, Avenir Next, Helvetica Neue, Arial` and a restrained serif display fallback `Iowan Old Style, Georgia` for select editorial moments. No external font request is required.

Spacing follows a fluid 4/8/12/16/24/32/48/64/96 scale. Corners are mostly 0–16px; pills are reserved for status and controls. Focus uses a 3px cyan/navy ring.
